# Тестирование раздела «Набор вопросов»

Задача №10, участник №4. Автоматические тесты используют **реальные функции проекта** и подставляют только строки из Excel и ответы Supabase. Никаких запросов к базе, опубликованному сайту и GitHub API тесты не выполняют.

## Запуск

Из корня репозитория (Node.js 22+), после установки зависимостей:

```bash
npm ci
node --test tests/question-bank-qa/question-bank.test.mjs
```

Используется TypeScript из `devDependencies`. Если зависимости ещё не установлены, команда может завершиться ошибкой среды.

## Что проверяется

- Пять типов вопросов, группировка, банк из 150 вопросов.
- Ошибки номеров, заголовков, баллов, ответов, типов и обязательных полей.
- API-клиент: создание банка, подтверждённая замена, запрет дубликата, редактирование, удаление и запрос истории.

## Ограничения

- Физическое чтение `.xlsx` через `read-excel-file` **не проверяется**: тестовые строки передаются напрямую в оригинальный парсер.
- API проверяется с имитацией ответов Supabase; реальная PostgreSQL, RLS, SQL-триггеры и транзакции **не проверяются**.
- Браузерный интерфейс **не проверяется**.

Исходники Backend, Excel и UI не меняются. Транспилированные файлы тестов записываются во временный системный каталог. См. `docs/QUESTION-BANK-QA.md`.
